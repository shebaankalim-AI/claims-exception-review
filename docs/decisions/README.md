# Decision notes

Short records of choices a reviewer would reasonably ask "why?" about. One page at most each.

Format: **Status**, **Context**, **Decision**, **Consequences**. Statuses are `Proposed`, `Accepted` and `Superseded by NNNN`. Never edit an accepted note to change the decision. Write a new one that supersedes it.
